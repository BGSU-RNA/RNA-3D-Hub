# About

RNA-3D-Hub contains the PHP code to present RNA 3D Hub data online.
Data is generated by code in the [https://github.com/BGSU-RNA/RNA-3D-Hub-core]RNA-3D-Hub-core repository and stored in the BGSU RNA Group database.

The "php8" branch is actively maintained and is the basis for the RNA 3D Hub website.
